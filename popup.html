Sites

    Options

    Only tabs on these sites get CORS headers, and only on their fetch/XHR, font, image and media responses. The page's exact origin is sent back instead of *, so logged-in requests keep working, and no other headers are changed. A server that answers the OPTIONS preflight with an error (404, 405…) can't be fixed by an extension.

    Blocked sites

      Blocked sites (and their subdomains) open a page that asks you to type a phrase. That unlocks the site for 10 minutes, then it's blocked again and open tabs on it go back to the blocked page. A site has to be unlocked before you can remove it.
